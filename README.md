# Сложно сосредоточиться

Проектная работа по вёрстке макета "Сложно сосредоточиться".  
Адаптивный сайт о прокрастинации и методах борьбы с откладыванием дел.

## Ссылка на GitHub Pages
https://kamilarachk.github.io/slozhno-sosredotochitsya-ad/

## Ссылка на репозиторий
https://github.com/kamilarachk/slozhno-sosredotochitsya-ad

## Описание проекта
Одностраничный сайт с информацией о:
- причинах прокрастинации
- методах борьбы с откладыванием дел
- последствиях промедления
- способах улучшить концентрацию

## Технологии
- HTML5
- CSS3 (Flexbox, Grid, медиазапросы)
- БЭМ-методология
- Адаптивная вёрстка (мобильные устройства и десктоп)
- Поддержка светлой и тёмной темы

## Функциональность
- Переключение цветовой темы (День/Авто/Неон)
- Адаптивность для разных разрешений экрана
- Анимации и интерактивные элементы
